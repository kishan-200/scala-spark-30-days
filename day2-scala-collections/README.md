# Day 2 — Scala Collections Practice

Part of my **30-Day Scala + Apache Spark Practice Journey**.

## Topics Covered

- `map`, `filter`, `flatMap`, `reduce`
- `Vector` and indexed access
- `Map` for product data
- `for`-comprehension
- Daily sales processing using Scala collections

## Programs

| Program | Description |
|---|---|
| `SalesOperationsDemo.scala` | Sales processing with `map`, `filter`, `flatMap`, and `reduce` |
| `CustomerVectorDemo.scala` | Customer records using `Vector` |
| `ProductMapDemo.scala` | Product quantities, prices, and inventory value using `Map` |
| `CustomerOrderDemo.scala` | Combines customers and orders using `for`-comprehension |
| `DailySalesSummary.scala` | Daily sales summary without Spark |

## Technologies

- Scala 2.11.12
- sbt
- Java 17
